# Linked List Implementation in C

This repository contains a basic Singly Linked List implementation written in C. 
It is developed to practice dynamic memory allocation, pointer arithmetic, and basic data structure operations.

## Features
- Dynamic node creation using `malloc` and memory management with `free`
- Inserting nodes (at the beginning, end, or a specific position)
- Deleting nodes
- Traversing and displaying the list

## How to Run
1. Compile the code using a C compiler (e.g., GCC):
   gcc main.c -o linked_lists
2. Run the executable:
   ./linked_lists
